# Palmer Penguins Mini Project

## Project Overview

This project demonstrates a reproducible research workflow using the palmerpenguins dataset. The goal is to establish a clear project structure, data documentation, version control, and manuscript preparation.

## Directory Structure

-   data/raw: Original dataset exported from the palmerpenguins R package
-   data/processed: Cleaned dataset with complete cases and a derived body mass variable
-   docs: Draft manuscript files

## Data Processing

Raw data were exported directly from the palmerpenguins package. Processed data remove observations with missing values and include body mass converted from grams to kilograms.

## Reproducibility

This project uses an RStudio Project, GitHub for version control, and OSF for project management and sharing.
