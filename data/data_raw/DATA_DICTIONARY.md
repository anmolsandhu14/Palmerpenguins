# Processed Data Dictionary

## Dataset Information

Derived from the raw palmerpenguins dataset.

Processing Steps: - Selected variables: species, flipper_length_mm, body_mass_g - Removed rows with missing values in any of these variables

Final Dimensions: 342 rows x 3 columns\
Dataset contains no missing values.

## Variables

-   species\
    Penguin species (Adelie, Chinstrap, Gentoo)

-   flipper_length_mm\
    Flipper length in millimeters

-   body_mass_g\
    Body mass in grams
